Question 2 Part i

Infix:
A + B * ( C - D ) / E

Postfix:
A B C D - * E / +

Logic:
1. A operand hai, result mein add hota hai.
2. + stack mein push hota hai.
3. B result mein add hota hai.
4. * ki precedence + se zyada hai, is liye * stack mein push hota hai.
5. ( stack mein push hota hai.
6. C result mein add hota hai.
7. - stack mein push hota hai.
8. D result mein add hota hai.
9. ) par - pop hota hai aur ( remove hota hai.
10. * pop hota hai, phir / stack mein push hota hai.
11. E result mein add hota hai.
12. End par / aur + pop hote hain.

Stack trace:
