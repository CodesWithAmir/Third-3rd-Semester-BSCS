ASSIGNMENT 1 - STACK CONVERSION LOGIC

1. INFIX TO POSTFIX METHOD

Step 1: Read the infix expression from left to right.
Step 2: If the character is an operand, add it to the postfix result.
Step 3: If the character is '(', push it into the stack.
Step 4: If the character is ')', pop operators until '(' is found.
Step 5: If the character is an operator, compare its precedence with the
        operator at the top of the stack.
Step 6: Pop higher-precedence operators before pushing the current operator.
Step 7: For equal precedence, pop first when the current operator is
        left-associative.
Step 8: After reading the complete expression, pop all remaining operators.

2. INFIX TO PREFIX METHOD

Step 1: Reverse the infix expression.
Step 2: Change '(' into ')' and ')' into '('.
Step 3: Convert the changed expression into postfix by using the stack.
Step 4: Reverse the postfix result.
Step 5: The final result is the prefix expression.

3. STACK METHODS USED IN THE PROGRAM

isEmpty()
    Checks whether top is -1.

isFull()
    Checks whether top has reached the last array position.

Push(value)
    Moves top upward and stores the value.

Pop()
    Returns the top value and moves top downward.

Top()
    Returns the top value without removing it.

precedence(operator)
    Returns 3 for '^', 2 for '*', '/', '%', and 1 for '+' and '-'.

isRightAssociative(operator)
    Returns true only for '^'. Other listed operators are left-associative.
