# Third Semester BSCS DSA

C++ programs and lab exercises for the third-semester Data Structures and Algorithms course.

## Contents

### Lab-Lecture 1

- `Array/`
  - Dynamic arrays
  - Linear search
  - Binary search
- `Sorting/`
  - Bubble sort
  - Selection sort
  - Insertion sort
  - Sorting combined with binary search
- `Stack/`
  - Dynamic integer stack
  - Push and pop operations
  - Overflow and underflow handling

Each exercise is a separate C++ source file and can be compiled independently.

## Compile and Run

From the repository root, compile a program with a C++ compiler such as `g++`:

```bash
g++ "Lab-Lecture 1/Sorting/SELECTION SORT ALGORITHM e3.cpp" -o selection-sort
```

Run the compiled program:

```bash
./selection-sort
```

On Windows PowerShell, run the executable with:

```powershell
.\selection-sort.exe
```

## Requirements

- A C++ compiler with C++11 or later support
- A terminal or IDE for compiling and running the exercises
